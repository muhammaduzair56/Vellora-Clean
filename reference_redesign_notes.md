# Reference Redesign Notes — martillacleaning.com

## Patterns worth adapting

The reference site uses a persistent rounded header with Home, About, Services, Blogs, Contact and a prominent booking action. Its homepage establishes a strong hero, a service catalogue with specific service cards, a process explanation, a company-difference section, add-ons, FAQs, contact/booking area and a content-heavy footer.

The blog experience uses a clear blog hero followed by a visual article grid. Each article card has an image, publication date, title, summary and a read-article action. The reference also uses a large library of practical cleaning topics and a direct booking CTA.

## Original Vellora Clean adaptation

Vellora Clean will keep the useful information hierarchy but not reproduce the reference site's copy, layout, exact imagery, components or visual treatment. The redesign will use Vellora's quiet-luxury navy, mint and lavender system, an editorial sticky navbar, a more asymmetric hero, service-led page sections, original local positioning and original blog content.

The blog will be a frontend-only experience with a `/blog` listing route and article detail route(s). Article content will be static for now and clearly separated in constants so a CMS or backend can be added later without changing the visual structure.

## User-requested changes

- Keep the top navbar sticky on scroll.
- Add an A-to-Z style navigation menu with clear page anchors/routes.
- Add a dedicated Blog page and article detail experience.
- Add more high-quality cleaning and interior images.
- Make the result original rather than a same-to-same clone.
- Preserve responsive behavior and the approved Vellora Clean branding.
